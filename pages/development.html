Dev / Code

Selected coding and development activity across open-source tooling, research releases, and hands-on AI engineering systems.

agent-memory-runtime

A local-first, provider-agnostic persistent memory runtime for AI agents, with SQLite storage, retrieval, policy, context compilation, extraction, and OpenAI, Anthropic, and Ollama adapters.

streamsampler

Deterministic building blocks for ML data pipelines, covering weighted dataset mixing, checkpoint and resume, distributed sample partitioning, curriculum schedules, and replayable data sources.

sona-lab

Open-source neural speech synthesis lab for pre-training, SFT, and RLHF on SpeechLMs and audio codecs, with reproducible local and multi-GPU workflows.

OSDN

Code and data release for Towards Open Set Deep Networks (CVPR 2016), including OpenMax, LibMR-based Weibull fitting, and an open-set recognition preprocessing pipeline.

OWR

MATLAB implementation of the Nearest Non-Outlier method and open-world recognition protocol from Towards Open World Recognition (CVPR 2015), evaluating open-set and incremental learning on ImageNet features.

pyphasesym

Python implementation of phase symmetry analysis: a contrast-invariant image measure for detecting lines and blobs using FFT-based filters.

geo-blur

An object-category recognition pipeline using geometric-blur descriptors around SIFT keypoints with nearest-neighbor retrieval and SVM classification.

rls-lab

Python implementations of linear and nonlinear regularized least squares, validated against Ryan Rifkin's MATLAB reference code with leave-one-out error analysis.
